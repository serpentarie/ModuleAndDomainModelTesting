# ModuleAndDomainModelTesting

## Цели работы
1.  Реализация и модульное тестирование разложения функции `sec(x)` в степенной ряд.
2.  Реализация и тестирование алгоритма хеш-таблицы с открытой адресацией.
3.  Создание доменной модели по следующему тексту: "Артур, нервничая, вошел следом и был ошеломлен, увидев развалившегося в кресле человека, положившего ноги на пульт управления и ковыряющего левой рукой в зубах правой головы. Правая голова, казалось, была всецело занята этим, но зато левая улыбалась широко и непринужденно. Количество вещей, видя которые, Артур не верил своим глазам, все росло. Его челюсть отвисла.".

## Выполненные задачи

### 1. Тестирование функции `sec(x)`
Был реализован класс, содержащий метод для вычисления секанса через ряд Тейлора. Созданы модульные тесты для проверки корректности вычислений, включая граничные значения с точками вблизи разрывов функции, стандартные значения с характерными точками и также проверку сходимости.

### 2. Алгоритм хеш-таблицы
Реализована структура данных хеш-таблица с открытой адресацией, метод цепочек. Проведено тестирование трассировки по характерным точкам алгоритма. Составлены тестовые сценарии для проверки коллизий: добавление элементов с одинаковым хешем и проверка их корректного размещения в цепочке соответствующего бакета.

### 3. Доменная модель
На основе текста об Артуре и двухголовом человеке была спроектирована объектная модель.

Созданные сущности:
- `Human` — с состояниями (нервничает, ошеломлен) и действиями (войти, не верить глазам, челюсть отвисла).
-   `Alien` — имеет свойства (развалился в кресле, положил ноги на пульт).
-   `Head` — связанная сущность. Левая (улыбается), Правая (занята ковырянием в зубах).
Проверена корректность взаимодействия объектов, а также атрибуты голов.
